The ThreatsWe Focus On

Common attack patterns in fintech, each mapped to MITRE ATT&CK techniques.

ThreatT1190

API abuse

Broken object-level authorization and missing rate limits on payment APIs.

ThreatT1530 · T1078.004

Cloud misconfiguration

Public storage, open security groups and over-privileged identities.

ThreatT1110.004 · T1621

Credential stuffing & MFA fatigue

Automated attacks on login and OTP flows.

ThreatT1552

Leaked secrets

Credentials exposed in code repositories or build pipelines.

SystemsWe Cover

Select a system to see what we assess and what our SOC watches for.

Payment & wallet APIs

Transfers, top-ups, balances and merchant APIs.

Exposure checks · Line A

  • API discovery including undocumented endpoints
  • API scanning per release
  • Rate-limit and authorization review

What the SOC watches · Line B

  • Enumeration of wallet IDs
  • Abnormal transfer velocity
  • Exploitation attempts on the API gateway
Typical data sources: API gateway, WAF, application logs

Cloud platform

Kubernetes, managed databases and storage.

Exposure checks · Line A

  • Cloud configuration against standards
  • Public exposure of storage and services
  • Identity permission review

What the SOC watches · Line B

  • Suspicious use of cloud access keys
  • Changes to storage access policies
  • Unusual workloads
Typical data sources: Cloud audit logs, Kubernetes audit

Mobile app

Customer wallet app on Android and iOS.

Exposure checks · Line A

  • Hard-coded secrets and endpoints
  • Backend exposure
  • Certificate checks

What the SOC watches · Line B

  • Abuse of app APIs from emulators
  • Repackaged or fake apps reported
  • Brand phishing campaigns
Typical data sources: API telemetry, brand monitoring

KYC & customer data

Identity documents and customer profiles.

Exposure checks · Line A

  • Access-control scanning
  • Storage exposure checks
  • Third-party KYC integration review

What the SOC watches · Line B

  • Bulk access to KYC records
  • Transfers to external storage
  • Unusual support-staff access
Typical data sources: Application logs, database audit, cloud audit

Code & pipelines

Repositories, pipelines and secrets.

Exposure checks · Line A

  • Security checks in the build pipeline
  • Pipeline exposure review
  • Dependency risk reporting

What the SOC watches · Line B

  • Leaked credentials used in cloud
  • Unauthorized pipeline changes
  • Unusual repository cloning
Typical data sources: Code platform, CI logs, cloud audit
